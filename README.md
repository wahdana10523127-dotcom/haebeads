# Haebeads

Sistem Informasi Pengelolaan Persediaan dan Laporan Keuangan UMKM Haebeads Berbasis Web.

## Deskripsi Sistem

Haebeads merupakan sistem informasi berbasis web yang digunakan untuk membantu pengelolaan persediaan dan laporan keuangan pada UMKM. Sistem ini menyediakan fitur pengelolaan data produk, bahan baku, stok, transaksi, perhitungan HPP, serta laporan usaha.

## Fitur Sistem

- Login pengguna
- Pengelolaan data produk
- Pengelolaan data bahan baku
- Pencatatan stok masuk
- Pencatatan stok keluar
- Pencatatan transaksi penjualan
- Pencatatan pengeluaran usaha
- Perhitungan Harga Pokok Produksi (HPP)
- Perhitungan Reorder Point (ROP)
- Laporan persediaan dan keuangan
- Dashboard informasi usaha
